Why not cloud?

  • Perpetual license available – you pay just once
  • No internet required. So, you don’t need to send heavy image or video stream payloads over the network and pay for wide broadband connection(s)
  • All processing tasks are done on device. If you’re collecting data from multiple remote cameras, you can place a small ~100$ microPC (ex. RockPi) device together with each camera (or bundle of cameras) and just push pretty processing results to the server as, for example, JSON over cheap 64kps GPRS connection. Besides, if the connection brokes, no events will be lost, and can be synchronized after connection recovery.
  • On-Premise solutions outperform almost all known cloud-based
  • You can aggregate processing results from thousands of remote devices on a single VPS server, as it deals with simple JSON data.
